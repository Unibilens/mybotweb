Privacy Policy

Last Updated: September 13, 2026

This Privacy Policy explains how Husky ("Bot", "we", "our") collects, uses, stores, and protects user and server information when you interact with the bot on Discord.

🔒 Your Privacy Matters:
Husky NEVER reads, records, or stores the actual text content of your messages, nor does it record or listen to voice audio in channels. We only track activity metrics (such as message count and time spent in voice) to award experience points (XP).

1. Information We Collect

Husky collects only the minimum data required to function as an activity and leveling system:

  • User Identifiers: Discord User ID, username, and avatar hash (used to link XP to your account and display leaderboards).
  • Guild (Server) Identifiers: Server ID, channel IDs, and role IDs (used to apply custom server settings and assign level roles).
  • Activity Metrics:
    • Message activity count (increments of messages sent to calculate text XP).
    • Voice activity duration (time connected to voice channels to calculate voice XP).
    • Invite counts and bonus XP allocations.
  • Server Configurations: Admin settings such as role rewards, XP rates, cooldowns, and notification channels.

2. How We Use Collected Data

The information collected is used solely to:

  • Calculate and maintain accurate user levels, rankings, and leaderboards.
  • Automatically award level roles configured by server administrators.
  • Send level-up or voice session summary notifications (if enabled).
  • Provide server statistics via commands such as /stats and /rank.

3. Data Storage & Security

All data is stored in a private, secured database with restricted access. We employ industry-standard practices to protect your data from unauthorized access, alteration, or disclosure.

We do not sell, trade, or rent your personal or guild data to third parties under any circumstances.

4. Data Retention & Deletion Rights

We retain your activity data for as long as the bot remains in your Discord server to maintain continuity of leaderboards and levels.

  • Server Reset: Server administrators can wipe all server data and leaderboards at any time using the /reset command.
  • Data Deletion Request: If an individual user or server owner wishes to have their data completely removed from our database, you may submit a request through our Support Server, and we will promptly delete it.

5. Third-Party Services

Husky interacts with the official Discord API. By using the bot, you are also subject to Discord's Privacy Policy.

6. Changes to This Privacy Policy

We may update this Privacy Policy periodically to reflect new features or legal requirements. Updates will be posted directly to this page with an updated revision date.
