Commands

Simple, Intuitive Slash Commands

No complicated setups or messy prefixes. Just type / in your server and start using Husky.

/rank

View your own or another member's rank card, current level, XP, and rank standing.

/leaderboard

Display the server leaderboard ranking the most active chatters and voice users.

/rewards

List all available level role rewards and requirements configured on the server.

/help

Get an overview of bot commands, tips, and direct links to the support server.
